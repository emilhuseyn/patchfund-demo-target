# tinyshare

A deliberately small file-sharing server (Node 22, no dependencies). It is the target of the
[Patch Fund](https://github.com/emilhuseyn/patch-fund) demo at NEAR HACKATHON 2026: its open issues are real security bugs,
and each one carries a bounty in the demo DAO `patchfund-emilh.sputnikv2.testnet` on NEAR testnet. Fixes are paid from the
DAO treasury when their pull request is merged.

Do not deploy it. `npm start` runs it on port 8080; `npm test` runs the tests.
